# Travel & Tourism Data Analysis – 2026

## Project Overview

This project analyzes travel and tourism data from 80 countries for the year 2026 using Python.

The main objective is to explore tourism patterns, travel costs, tourist arrivals, and destination characteristics through Exploratory Data Analysis (EDA) and data visualization.

## Dataset

The dataset contains information for 80 countries in 2026.

### Main Variables

- Country
- Continent
- Year
- Tourist Arrivals
- Average Hotel Cost (USD)
- Average Food Cost (USD)
- Average Transport Cost (USD)
- Average Daily Budget (USD)
- Average Temperature (°C)
- Nature Score
- Culture Score
- Safety Score

## Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Analysis Performed

The project includes:

- Data loading and inspection
- Data cleaning
- Descriptive statistics
- Exploratory Data Analysis (EDA)
- Country comparisons
- Tourism cost analysis
- Tourist arrival analysis
- Correlation analysis
- Data visualization

## Visualizations

The project includes different types of graphs, such as:

- Line charts
- Scatter plots
- Heatmaps

### Scatter Plot Examples

- Tourist Arrivals vs Average Hotel Cost
- Tourist Arrivals vs Average Daily Budget
- Tourist Arrivals vs Nature Score
- Tourist Arrivals vs Safety Score

## Objective

The objective of this project is to understand how tourism, travel costs, and destination characteristics vary across different countries.

## Project Files

`Travel_Tourism.ipynb` – Python/Google Colab notebook containing the complete analysis.

`travel_tourism_80_countries_2026.csv` – Dataset used for the analysis.
